## How to Push Your Code from Replit to GitHub

Here's what you need to do:

### **Option 1: Via Replit's Built-in Git Integration (Easiest)**

1. **In your Replit project**, look for the "Version Control" or "Git" icon in the left sidebar (looks like a branch icon)

2. **Connect to GitHub**:
   - Click "Connect to GitHub"
   - Authorize Replit to access your GitHub account
   - Select the `attreidis/chatvault` repository

3. **Commit and push**:
   - Write commit message: "Initial commit - ChatVault v1"
   - Click "Commit & Push"

Done. Your code is now on GitHub.

---

### **Option 2: Manual via Replit Shell (More Control)**

If Replit's GUI isn't working, you can use the terminal:

1. **Open the Shell tab** in Replit

2. **Initialize Git** (if not already done):
```bash
git init
git add .
git commit -m "Initial commit - ChatVault v1"
```

3. **Connect to your GitHub repo**:
```bash
git remote add origin https://github.com/attreidis/chatvault.git
```

4. **Push to GitHub**:
```bash
git branch -M main
git push -u origin main
```

If it asks for credentials, you'll need a **Personal Access Token** (GitHub no longer accepts passwords):
- Go to GitHub → Settings → Developer Settings → Personal Access Tokens
- Generate a token with `repo` scope
- Use the token as your password when prompted

### **What You Should Include in the Repo**

Once you push, make sure you have:

1. **README.md** - Essential. Explains what ChatVault is, how to use it, how to deploy it
2. **LICENSE** - Pick one (MIT is standard for open source)
3. **.gitignore** - Don't commit node_modules, .env files, or database files
4. **All source code** - The client/, server/, shared/ folders you described earlier
